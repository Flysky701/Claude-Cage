# 0.0.2 集成测试包

## 安装后直接测试

1. 安装 `Cage-Open-Bundled-Preview-0.0.2.apk`。包名和调试签名与本轮交付的 0.0.1 一致，
   versionCode 从 1 增至 2，可作为覆盖更新，来宾组件不会因准备操作而卸载或覆盖。
2. 打开后等待自动准备完成。无需自行下载 microG；原包已在 APK 内。
3. 点“运行内置测试应用”：观察启动、持久化计数、本地 WebView 和包可见性。
   其中 Google HTTPS 按钮会发起一次普通 HEAD 请求，用于区分联网失败与账号流程失败。
4. 点“打开 microG 设置”和“添加 Google 测试账号”，验证手机上的实际页面和登录行为。
5. 失败时复制首页准备记录或测试应用结果，并附实际操作步骤。记录不包含账号凭证。

网络沿用手机现有设置，不修改系统 VPN。测试应用本地计数用于重启后检查数据是否保留，
并非隔离、安全或认证测试通过的标志。当前环境没有手机，本次没有执行登录或实际对话。

## 包含的内容

| 组件 | 来源 | 处理 |
|---|---|---|
| Cage 宿主与 BlackBox/Dobby 内核 | 固定公开源码及本仓库补丁 | 本轮编译 |
| Cage 内置测试 APK | `project/probe/` | 单独编译为真实来宾 APK，不是假界面 |
| microG Services `0.3.18.252432` | microG 官方 GitHub Release | 原包内置，保留原始签名和全部字节 |
| microG Companion `0.3.18.40226` | 同一官方 Release | 原包内置；不是 Google Play 商店 |
| 初始化与快捷入口 | `BundledApps.java`、`HomeActivity.java` | 在用户 0 的来宾空间准备，校验后安装；已有组件跳过 |

没有内置 Claude 或 Google 官方 Play 商店；没有自动商店下载和原版 Claude 分包导入。
这次尽量减少容器与 microG 测试的手工准备，尚未达到安装后直接使用 Claude 的目标。

## 配套兼容改动

- 自动准备直接调用来宾包管理服务，避免包装层的个人区查询回退。
- 去掉上游 `GmsProxy`、`GoogleAccountManagerProxy`、`AuthenticationProxy` 演示 hook 注册。
- 签名信息从真实来宾 APK 查询，不借用个人区同包名应用的签名。
- 未实现的两阶段账号会话明确返回不支持，不转交个人区账号服务。
- Android 16 账号策略查询保留系统实际返回值，仅将调用归属修正为实际宿主包。

以上是源码和产物层面的检查，不代表 Binder、WebView、签名兼容或服务端登录已在手机上通过。
原先上游许可声明冲突仍保留在组件说明中，本次交付为用户私下测试，不创建公开发行版。
