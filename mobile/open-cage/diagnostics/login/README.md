# Claude 登录证明的只读定位

适用于原签名 Claude `1.261113.19` / `26111319`。类名来自此版本的静态分析，
不能直接用于其他版本。`LoginTrace.java` 不参与 Cage APK 构建。

使用 JDK 17 编译到本地临时目录，将 ADB 端口转发到 **Cage UID 下的 Claude PID**。
`LoginTrace <port> poll` 在 45 秒窗口内持续观察，不因首次看到请求与分支对象提前退出；
`LoginTrace <port> snapshot` 只读取一次当前仍存活的请求和错误对象。
结束后删除所建端口转发。仅在用户已授权登录测试时手动触发登录。

仅输出字段存在性、长度、固定位置的错误码与枚举。不会调用目标方法、修改字段、
安装断点、打印请求正文、账号、验证码、密码、令牌、Cookie 或响应正文。
对象可能已被回收；未观察到对象不等于请求缺少字段。调试观察不能替代无调试复测。请求类可能先创建中间对象、再创建带证明的最终对象；
持续观察能减少早退漏掉后续对象，但仍不等于观察了最终序列化请求。

2026-11-16 实测：Google 凭据存在；旧字段 `play_integrity_token` 存在（1443 字符）；
可选 `client_attestation` 为空；服务器错误对象是
`ClaudeApiError$InvalidRequestError`，枚举 `MISSING_CLIENT_ATTESTATION`，
错误码 `missing_client_attestation`。这些是同版本代码与真机对象的对应关系，
**不能据此断言给可选字段补值便能登录**；也没有解码 Claude 项目的完整性令牌。

诊断开发中曾尝试方法事件/断点，Android 16 JDWP 出现参数槽错误和来宾退出。
最终实现已移除该路径，只保留已在真机运行成功的有界对象读取。
账号数据与运行 APK 未修改；最终验收仍须新开来宾进程、断开调试器后操作。

## 新旧证明分支与配置对照

`LoginTrace` 读取 `ps3` 中的新旧证明结果和 `lir` 的固定遥测字段，记录旧证明生成结果、
新证明是否尝试、失败枚举与耗时。`challengeAttempted=false` 表示观察到的该分支对象没有
新证明结果；对象未观察到或已回收时，不应推导为“未尝试”。一次快照中的错误对象也可能
来自较早请求，需结合新进程首次登录和无调试复测判断。

`FlagState.java` 归档了同版本已用的只读配置观察器。使用同一 JDK 编译，运行
`FlagState <port>`，记录已加载配置数量、四项登录开关的存在性/允许值、覆盖标志及本地
尝试计数。未知字符串只输出占位符；不输出配置全集、账号、令牌、请求或响应正文。
观察器不调用目标方法、不修改开关或限流状态，不参与 Cage APK 构建。

2026-11-16 的 Cage 冷启动记录：旧证明 `MINTED`，耗时 5644 ms，
`challengeAttempted=false`；请求有旧证明，`client_attestation` 为空。
运行时配置共 44 项，凭据绑定证明与拒绝补救开关均无服务端记录、无本地覆盖；
限流计数为 1，没有封锁时间。这轮证据支持“分支未触发”，不支持延长超时作为修复。
上述状态不能推出强制开启开关会获得服务端认可，也不能替代同版本 GBox 新登录对照。
