# 轻量 DEMO 恢复代码

本目录从手机上与 2026-11-14 报告对应的 APK 恢复，最初包含 123 个可编辑、可重新汇编的 Smali 源文件。安装流程修复后为 126 个 Smali 文件及 3 个新增 Java 文件。输入身份记录在 `recovery.json`；恢复的 Smali 不是原始 Java 文件。

`smali/` 是原基础壳中有新增兼容修改的 21 个类，其中 3 个是本轮补充的后台任务适配；`smali_classes2/` 和 `smali_classes3/` 保留两个附加 DEX 的全部代码。其余基础类和资源从经过身份核对的输入 APK 取得。

构建入口为 `build.py`。构建方式、签名限制、并存测试包和验证边界见 [恢复说明](../../recovery/README.md)。不要用不同密钥的包覆盖原 DEMO 或卸载原 DEMO。

商店安装入口现在由 `java/io/github/leexeo/cage/space/GuestInstaller.java` 覆盖原 Smali 占位实现。构建时先编译 Java，再合入附加 DEX；其余恢复代码仍沿用 Smali。

当前支持 Claude 的完整安装会话：创建、查询、分包写入与续写、fsync、取消、提交、进度回调和安装结果回执。会话归属由空间服务核对实际调用进程；文件留在恢复空间的私有目录。提交复用 `ClaudeBundle` 的原签名、分包和升级校验，只有真实 Play 会话安装成功后才记录 Play 为安装来源。没有改变 Play Integrity 或许可结果。多应用会话、staged 安装、继承式更新及其他应用安装尚不支持。

`SharedGateway.java` 读取当前系统 VPN 和断网保护状态，让恢复副本使用手机已经开启的网关。内部检查读取未经过空间屏蔽的系统连接；应用可见的网络屏蔽继续保留。只有本应用的活动网络经过 VPN、系统断网保护开启且本应用不在豁免名单中才允许启动，读取失败则阻止启动。此检查适用于当前实测的 Android 16 / target 28 组合；没有切换网关或申请修改系统安全设置的权限。

2026-11-14 真机结果：安装器写入、续写、fsync、读取、会话归属、路径限制、取消及错误 APK 的失败回执通过。使用现成的 3 个原版 Claude 分包实际提交安装，返回 `STATUS_SUCCESS`，应用可启动。该次会话归属空间，安装来源仍是空间导入。

Google 邮箱框和测试账号登录已通过。组件使用 microG `0.3.18.252432`、Play `38.4.22-21` 和 Claude `1.261111.19`；测试中较新的 Play `45.7.17-31` 触发兼容错误，已备份其恢复空间内的测试数据并换回报告版本，未删除 microG 账号。

商店确实创建了自己的安装会话，但下载仍未完成。已修复 `schedule`、`enqueue`、`cancel` 错读 Android 新增 namespace 参数的问题；真机任务由直接失败推进到系统队列后，仍出现任务记录为空、非 JobService 类型转换失败及语言接口权限错误。没有把商店下载或 Play 许可标为通过。

Claude 的 Google 登录和邮件登录均返回无法经 Google Play 验证，邮件未发出；原生登录未成功。原空间和原账号未更新、清除或迁移，原网关及系统断网保护保持开启，本次未停网关重测断流。具体证据见 [验证记录](../../recovery/play-installer-validation.json)，测试入口位于 `../../recovery/tests/`。
