# Cage Windows 轻量沙箱整合测试版

双击 `Cage.exe`。本版使用 Cage 原来的账户、首次安装页面、工作台、侧栏和设置。

首次安装中的系统选择改为 **Windows 轻量沙箱**。点击“下载并安装轻量沙箱”，程序会从 Sandboxie 官方发行页下载固定版本，检查 SHA-256 与发布者签名，调用官方安装器，再检查驱动、服务和内核网络过滤。出现 Windows 管理员授权时需要确认；不会自动重启电脑。Python 和代理核心已随包提供，无需手工安装或填写路径。

已有完整 Sandboxie 安装会复用，不自动降级。首次启用内核过滤前保留原 Sandboxie 配置备份；现有盒仍有程序运行时不切换该全局功能。停止下载保留下载记录；已获得系统授权的官方安装程序可能继续运行，请等待它结束再重试。

## 当前能力

| 功能 | 本版状态 |
|---|---|
| 账户、密码保险箱、外观、收藏、代理来源、诊断 | 使用 Cage 原有实现 |
| 项目 | 保留原项目记录；只有明确选择的目录可参与空间共享，内嵌编辑器尚未开放 |
| 轻量沙箱组件 | 自动下载、安装、检查与失败重试已接入 |
| 浏览器与 Claude 网页 | 接入原地址栏、标签页、收藏和浏览器画面；只有当前应用监控通过后才启动盒内 Edge/Chrome |
| 普通终端 | 接入原输入、输出和窗口尺寸调整，实际 PowerShell 进程位于同一个持久空间 |
| Claude 终端 | 复用终端入口；需要空间中已登记的 x64 Claude 程序，托管账号登录和保存会话尚未开放 |
| Claude Desktop、内嵌编辑器、文件传输、音频和共享剪贴板 | 保持关闭，不能通过入口绕过能力检查 |

**组件安装完成不等于应用运行可用。本版不是全功能完成版。** 原有虚拟机传输接口不会用作轻量空间的备用运行路径，也没有宿主直接启动或跳过验证的选项。

点击“检查空间”后，应用自己的管理进程生成本次检查证据，并持续核对策略、进程归属、专用出口和实际 HTTPS 业务。界面显示检查结果及有效期；证据缺失、过期、配置改变或出口失效时拒绝新启动并撤销本次许可。浏览器和终端后端也检查许可，不能仅靠隐藏按钮放行。保存的报告不能在下一次启动中复用为许可。

本版使用免费内核阻断及自有适配组件。内核只允许空间连接受控的本机通道，其余连接保持阻断；不支持的联网调用可能失败。此范围不等于任意 Windows 程序、异步套接字、IPv6、UDP/QUIC、全部 DNS 调用和宿主服务代办路径均兼容。真实操作与故障注入结果以检查包旁的验证记录为准，不能用编译通过代替运行验证。

## 数据与使用

默认测试数据位于 `%USERPROFILE%\.claude-cage\windows-lite`，与日常 Cage 的账户、虚拟机和登录资料分开。显式指定 `CLAUDE_CAGE_CONFIG` 时使用同一个绝对路径及其目录；空间数据保存在该目录下的 `windows-lite` 子目录。停止、退出、替换或移除测试包均不删除空间数据。不要用初始化个人目录的方式处理安装失败。

如果提供了 `Start-current-review.cmd`，可用它继续打开同一份检查数据。测试包需要当前电脑已有 Microsoft WebView2；本包不是通用安装器，不替代正式 Cage 安装或自动更新。没有修改版本号、标签或发布应用。

轻量模式仅支持 Windows x64，复用宿主内核，不是独立 Windows 虚拟机。macOS、Linux 保留现有运行方式：Linux 已进行共用后台编译检查，macOS 完整后台需要 Apple 构建环境，本次未实测。不能把 Windows 探针结果视为三个平台通过。
